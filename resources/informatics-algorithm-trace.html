变量追踪

程序题的基础是“变量什么时候变成什么”。追踪表能把脑内想象变成可检查的步骤。

赋值不是等式

合計 ← 合計 + i 的意思是：先用旧的合計和 i 计算右边，再把结果写回合計。左边变量会被新值覆盖。

读法：「合計に、合計 + i の値を代入する」。

追踪表的列

  • 循环次数
  • 循环变量
  • 每个会变化的变量
  • 条件判断结果
  • 输出内容

易错点：输出在循环内还是循环外，会改变“出现几次输出”和“最后答案”。

代码示例：1 到 n 的合计

合計 ← 0
i を 1 から n まで 1 ずつ増やす:
  合計 ← 合計 + i
表示する(合計)

公式与程序的关系

这个程序计算 1 + 2 + ... + n。公式是 n(n + 1) / 2，但程序题常常要求你理解“它为什么得到这个值”。
