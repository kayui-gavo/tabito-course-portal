电磁学：楞次定律

磁铁靠近与远离：感应电流为什么反向？

从磁铁一侧向下观察线圈。左图中 N 极向下靠近，右图中 N 极向上远离。线圈总是通过感应电流，阻碍穿过线圈的磁通量发生变化。

ε = −N ΔΦ / Δt
1. 看左图外部向下的磁通量增加。线圈上端变为 N 极，排斥正在靠近的 N 极。
2. 看右图外部向下的磁通量减少。线圈上端变为 S 极，吸引正在远离的 N 极。
3. 看电流方向从磁铁侧观察，靠近时逆时针，远离时顺时针。

左：N 极靠近线圈

向下磁通量增加，线圈制造向上的磁场来阻碍增加。

SN
外部磁场↓
感应磁场↑
N
逆时针↺
磁通量增加 → 线圈上端为 N 极 → 排斥磁铁

右：N 极远离线圈

向下磁通量减少，线圈制造向下的磁场来阻碍减少。

SN
外部磁场↓
感应磁场↓
S
顺时针↻
磁通量减少 → 线圈上端为 S 极 → 吸引磁铁

两边会持续重复各自的单向运动。

判定顺序
  • 先判断外部磁通量是增加还是减少。
  • 再让线圈的磁场阻碍这个变化。
  • 最后用右手定则得到电流方向。
观察约定：电流方向均从磁铁侧（上方）观察。实际线圈中，电流的正负端还取决于导线的连接方式。
