二进制与编码

计算机内部只直接处理 0 和 1。整数、文字、图片和声音都要先变成数字，再用二进制保存或传输。

核心概念

二进制每一位只有 0 或 1。右端是 2^0，往左依次是 2^1、2^2、2^3。某一位是 1，就把对应的位权加到总和里。

例：10101101₂ = 128 + 32 + 8 + 4 + 1 = 173。

数据量

  • 1 bit 可以表示 2 种状态。
  • n bit 可以表示 2^n 种状态。
  • 1 byte = 8 bit，所以 1 byte 可表示 256 种状态。

考试题怎么问

  1. 把十进制数转成二进制。
  2. 根据 bit 数求能表示的最大值。
  3. 计算文字、图片、声音的大致数据量。
  4. 比较 bit 和 byte，注意单位换算。

易错点：1000₂ 不是一千，而是 8。KB、MB 的题目要先看题干是否按 1000 还是 1024 计算。

每次除以 2 得到一位余数。因为先得到的是低位，所以要把余数放到结果的左边。

读代码的关键

  • 余り是当前最低位。
  • 商会不断变小，直到 0。
  • 结果从右往左生成，所以拼接顺序不能反。
