波動：レンズ・球面鏡

薄いレンズと球面鏡の像

凸レンズ、凹レンズ、凹面鏡、凸面鏡を同じ式で比べます。実像はスクリーンに映せる像、虚像は光線の延長線上に見える像です。

1/a + 1/b = 1/f　倍率 m = -b/a
1. 種類を切り替える凸レンズ・凹面鏡は収束、凹レンズ・凸面鏡は発散として扱います。
2. 物体距離を変える焦点の内外で、実像と虚像がどう入れ替わるかを見ます。
3. 符号を確認するこのデモでは収束系を f > 0、発散系を f < 0 とします。
実像 b = 2.40 m

凸レンズで a > f なので、反対側に倒立実像ができます。

公式・重要結論
  • 薄いレンズ・球面鏡：1/a + 1/b = 1/f
  • 倍率：m = -b/a
  • 凸レンズ・凹面鏡：f > 0。凹レンズ・凸面鏡：f < 0。
  • b > 0 は実像、b < 0 は虚像として表示します。

作図ルール：軸に平行な光、中心または頂点を通る光を使います。破線は虚像を作る延長線です。
