条件分支与循环

条件分支决定程序走哪条路，循环决定同一处理重复几次。算法题最常考边界条件。

条件分支

条件为真时执行一组处理，否则执行另一组处理。多个条件出现时，要区分“且”和“或”。

もし 点数 >= 80 ならば:
  評価 ← "A"
そうでなければ:
  評価 ← "B"

循环

循环包括初始值、继续条件、更新。任何一个没看清，执行次数都会错。

  • for：次数通常比较明确。
  • while：只要条件为真就继续。
  • 循环变量必须在适当位置更新。

代码示例：FizzBuzz 型判断

もし x が 15 で割り切れる ならば:
  表示する("A")
そうでなく もし x が 3 で割り切れる ならば:
  表示する("B")
そうでなく もし x が 5 で割り切れる ならば:
  表示する("C")
そうでなければ:
  表示する(x)

条件按顺序检查。15 的倍数也能被 3 和 5 整除，所以必须先判断 15。

边界检查

  • < 与 ≤ 是否包含边界。
  • 分支顺序是否会遮住后面的条件。
  • 循环是从 0 开始还是从 1 开始。
  • 循环结束时变量已经更新到哪里。
