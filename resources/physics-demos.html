物理 Demo 集

只收录课堂上“动起来以后明显更容易懂”的内容。每个 Demo 都应该能让学生先看到现象、做出预测、改变一个条件，再用公式解释结果；单纯把公式画成图的内容不收录。

课堂精选 30 个力学 9波动 10热 2电磁学 4原子 5
课堂使用推荐一次只演示 2～5 分钟：先让学生预测，再播放或拖动一个参数，最后回到板书。演示中的长度和时间有时为便于观察而缩放；定量关系以页面显示的公式和数值为准。

力学

优先选择运动过程、受力关系、参考系和能量转化比静态图更有教学价值的内容。

9 个
动态实验放物运动

斜抛：横向等速，纵向落体斜方投射を横と縦に分けて見る

发射小球，速度、水平分量、竖直分量与重力加速度同步显示；最高点处也能看见水平速度仍然存在。

入门课程 第1讲发射 →
动态实验作用・反作用

重车和轻车互推，哪边受到的力更大作用・反作用と加速度

两台质量不同的小车由弹簧推开，两个力传感器读数始终等大反向，但轻车的加速度更大。

入门课程 第2讲释放小车 →
交互实验刚体平衡

把砝码放在哪里，跷跷板才会水平剛体のつり合いと力のモーメント

改变两侧质量和支点距离，让杆真的倾斜或重新平衡，直接体会“质量大不等于力矩一定大”。

入门课程 第2–3讲调平衡 →
动态实验机械能

小球下坡时，“高度”去了哪里力学的エネルギーの移り変わり

小球在U形轨道上往复运动，势能、动能与热的柱状图同步变化；还能切换有无摩擦。

入门课程 第3讲释放小球 →
动态实验碰撞

真的让两个物体撞起来1次元衝突・運動量・反発係数

选择同质量、完全非弹性或轻撞重的情形，播放碰撞过程，再比较碰撞前后的动量与动能。

入门课程 第4讲开始实验 →
动态圆周・天体

速度为什么沿切线，力为什么指向中心円運動と円軌道

物体连续绕圈运动，速度和向心加速度箭头实时转动；还可切换到人工卫星圆轨道。

入门课程 第5讲打开演示 →
动态单振动

弹簧振子与 x、v、a 同步运动単振動：変位・速度・加速度

连续播放振子的往复运动，并可停在右端、平衡位置和左端观察相位关系。

入门课程 第6讲打开演示 →
动态实验单摆

摆长变成2倍，周期会变成几倍単振り子：長さと周期

改变摆长、质量和初始角，边摆边比较理论周期；还能看到大振幅时小角近似开始失效。

入门课程 第6讲开始实验 →
动态解释惯性力

电车加速时，吊坠为什么会向后倾加速する座標系と慣性力

把地面参考系与车内参考系并排显示；改变车辆加速度，吊坠角度和惯性力同步变化。

入门课程 第6讲让电车加速 →

波动

传播、反射、叠加、共鸣、声音和光路都非常适合实时观察。

10 个
动态波的反射

固定端为什么“山变谷”，自由端却不变固定端反射と自由端反射

把一个脉冲送向端点，观察固定端与自由端反射时的相位差别，以及入射波和反射波重叠的瞬间。

波动基础发送脉冲 →
动态实验水面波

把水波槽搬到屏幕上水面波の干渉と回折

切换二点波源、单缝和双缝，改变波长与间距，直接观察干涉节线与回折的强弱。

波动专题打开水波槽 →
动态定常波

两列行波怎样叠成定常波定常波と節・腹

同时播放向右、向左传播的两列波和合成波，节为什么不动会直接显示出来。

波动基础打开演示 →
动态＋声音气柱共鸣

开管、闭管：看波形也听声音気柱共鳴と開管・閉管

切换开管和闭管，观察位移的节、腹和共鸣频率，并直接试听基本音与高次共鸣。

入门课程 第9讲打开演示 →
声音拍

440 Hz 和 444 Hz 一起响会发生什么うなりを「見る」・「聞く」

分别听两个纯音，再听合成音，用耳朵确认每秒4次的强弱变化。

入门课程 第9讲试听 →
动态＋声音多普勒效应

移动声源把波面“挤”到前方動く音源がつくる波面

声源一边移动一边发出波面，前方波长变短、后方变长，并可试听音高差。

入门课程 第9讲打开演示 →
交互全反射

拖到临界角，亲眼看见折射光消失屈折と全反射

改变入射角和折射率，折射光连续转动；越过临界角后只剩反射光。

入门课程 第10讲打开演示 →
交互实验偏光

把第二张偏光板转到90°，光会怎样偏光板と光の横波性

旋转两张偏光板的相对角度，屏幕亮度连续变化；90°时理想模型几乎全暗。

入门课程 第10讲旋转偏光板 →
交互成像

移动物体，像会跑到哪里薄いレンズと球面鏡の像

连续改变物距，实际光线、延长线和像的位置一起移动，焦点内外的变化会很直观。

入门课程 第10讲打开演示 →
交互光的干涉

把光从紫色拖到红色，看条纹怎么变ヤングの二重スリット

改变波长、缝间距和屏距，屏上的明暗条纹即时变化，直接对应 Δx=Lλ/d。

入门课程 第10讲打开演示 →

热

只保留能把看不见的分子运动和做功过程直接变成可观察现象的内容。

2 个
动态实验气体分子运动

加热或压缩时，分子到底发生了什么気体分子運動と圧力

大量分子在活塞内运动；改变温度和体积，观察速率、碰撞频度与平均压力的变化。

入门课程 第13讲打开分子模型 →
动态实验绝热压缩

猛压活塞，空气为什么会变热断熱圧縮と内部エネルギー

快速压缩气体，分子运动与温度计同时变化，把“对气体做功→内能增加”变成可见过程。

入门课程 第12–13讲快速压缩 →

电磁学

重点展示方向随位置或运动连续变化，以及电磁感应中最难从静态图看出的时间关系。

4 个
交互实验电流的磁场

拿着方位磁针绕导线走一圈直線電流がつくる磁界

移动方位磁针或反转电流，针的方向会随位置实时变化，把右手定则变成可观察的现象。

入门课程 第17–18讲移动方位磁针 →
动态实验洛伦兹力

带电粒子进磁场后为什么会拐弯磁界中の荷電粒子

反转电荷符号或磁场方向，轨道随即反转；速度和洛伦兹力箭头始终保持垂直。

入门课程 第18讲发射粒子 →
动态楞次定律

磁铁靠近、远离时，电流为什么反向レンツの法則

N极或S极反复靠近、远离线圈，外磁通、感应磁场、线圈极性和电流方向同步显示。

入门课程 第19讲打开演示 →
动态交流发电

转动线圈，正弦交流是怎么产生的回転コイルと交流発電

线圈旋转的同时显示磁通和感应电动势波形，直接看到两者为什么相差四分之一周期。

入门课程 第19讲启动发电机 →

原子

选择经典实验、波粒二象性和统计现象，让“为什么得到这个模型”比背结论更清楚。

5 个
动态实验光电效应

强红光和弱高频光，谁能打出电子光電効果

让光子不断撞击金属，分别改变频率和光强，直接观察阈频、电子最大动能和放出数量的区别。

入门课程 第20讲开始实验 →
随机累积电子的波动性

电子一颗一颗落下，为什么最后出现回折环電子回折と物質波

单个电子以点状被探测，但数百个事件累积后逐渐显出回折图样；提高加速电压后环会收缩。

入门课程 第20讲发射电子 →
动态实验α散射

100个 α 粒子里，为什么只有极少数大角度反弹ラザフォード散乱

连续发射 α 粒子，看大多数直穿、少数强烈偏转，从实验现象理解原子核为什么必须很小而集中。

入门课程 第20讲发射 α 粒子 →
动态氢光谱

电子跳一次，为什么只发出某一种颜色水素原子の線スペクトル

选择能级跃迁，电子落下同时发出对应波长的光；可直接比较 Balmer 系列与紫外区跃迁。

入门课程 第20讲放出光子 →
随机实验半减期

每过一个半减期，真的会刚好剩一半吗半減期の確率実験

每个原子核独立随机决定是否衰变；重复实验会得到不同结果，再与理论曲线比较。

入门课程 第20讲开始实验 →
