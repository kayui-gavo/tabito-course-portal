算法效率

算法效率关注数据量变大时，处理次数怎样增长。共通考试常用图表或表格比较不同算法。

为什么要看效率

数据很少时，很多算法都能马上结束。但数据量变大后，处理次数的增长方式会产生巨大差异。

O(1)

不随 n 变化。

O(n)

n 变 2 倍，处理约 2 倍。

O(n²)

n 变 2 倍，处理约 4 倍。

考试题怎么判断

  • 一层循环通常是 O(n)。
  • 两层嵌套循环常常是 O(n²)。
  • 每次把范围减半，常见于二分搜索。
  • 只取一个位置的值，通常是 O(1)。

代码示例：一层循环

合計 ← 0
i を 1 から n まで 1 ずつ増やす:
  合計 ← 合計 + データ[i]

循环执行 n 次，所以处理次数与 n 成正比。

代码示例：两层循环

i を 1 から n まで 1 ずつ増やす:
  j を 1 から n まで 1 ずつ増やす:
    表[i][j] を処理する

外层 n 次，内层每次 n 次，总共约 n² 次。
