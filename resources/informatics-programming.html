计算机与程序设计

这一部分的重点不是记住某一种编程语言，而是读懂数据如何被表示、程序如何一步一步改变变量，以及算法为什么能稳定得到结果。

二进制与位

计算机内部用 0 和 1 表示信息。一个二进制位叫 bit，8 bit 通常称为 1 byte。做题时要能在十进制和二进制之间转换。

重要结论：从右往左，第 k 位的权重是 2^k。8 bit 无符号整数的范围是 0 到 255。

173 = 10101101₂

典型题的看法

  1. 先写出位权：128, 64, 32, 16, 8, 4, 2, 1。
  2. 从最大的位权开始，能减就写 1，不能减就写 0。
  3. 转换字符编码时，注意题目给的是十进制、十六进制还是二进制。

容易错的地方

  • 把 1000₂ 看成一千，而不是 8。
  • 忘记最高位的权重随 bit 数增加而改变。
  • 把数据量单位 bit 和 byte 混用。

共通考试的程序题通常用初见也能读懂的伪代码。解题时不要凭感觉跳到结论，而要把变量每一步的值写出来。

读程序的固定步骤

  1. 确认输入、输出和初始值。
  2. 把循环条件和更新位置圈出来。
  3. 每循环一次记录一次变量。
  4. 最后检查输出发生在循环内还是循环后。

考试意识：程序题常考“第几次循环后变量是多少”“条件分支走哪一边”“数组下标有没有越界”。

模型化与模拟

现实问题太复杂时，可以用变量和规则建立模型，再用程序重复计算。模拟结果不是绝对真实，而是“在设定条件下会怎样”。

  • 先明确假设：忽略什么、保留什么。
  • 每一步如何更新状态。
  • 结果是否会受初始值或随机数影响。
