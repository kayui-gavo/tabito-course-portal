解释数据时的注意点

  • 相关不等于因果。两个量一起变化，不代表其中一个一定导致另一个。
  • 离群值可能大幅改变平均值、相关係数和回归线。
  • 图表的坐标轴范围会影响读者的直观判断。

考试意识：看到数据题，先问“数据来源是什么”“样本数是否足够”“图表是否支持题目结论”。

网络分包通信

网络传输中，信息常被拆成多个 packet。packet 可以不同顺序到达，接收方需要根据序号重新组合；如果丢失，则需要重传。

网络知识点

  • 协议：通信双方共同遵守的规则。
  • IP 地址：网络中的位置标识。
  • DNS：把域名转换为 IP 地址的机制。
  • 暗号化与认证：保护内容和确认对方身份。

数据库与表格处理

数据活用题经常要求筛选、排序、分组、汇总。关键是看清字段、条件和单位。

  1. 先确认每一列表示什么。
  2. 把筛选条件翻译成逻辑式。
  3. 按题目要求选择平均、合计、最大值或比例。
