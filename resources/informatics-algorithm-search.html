05 · linear search

线性搜索

线性搜索从头到尾逐个比较。它简单、可靠，适合没有排序的数据。

算法思路

  1. 从第一个数据开始。
  2. 把当前数据和目标比较。
  3. 相等就找到。
  4. 不相等就看下一个。
  5. 全部看完还没有，就判断不存在。

效率

  • 最好情况：第一个就是目标，只比较 1 次。
  • 最坏情况：目标在最后或不存在，比较 n 次。
  • 平均情况：大约比较 n / 2 次。

代码示例

見つかった ← 偽
位置 ← 0
i を 1 から データ数 まで 1 ずつ増やす:
  もし データ[i] = 目標 ならば:
    見つかった ← 真
    位置 ← i

是否要立刻停止

找到后可以继续循环，也可以用条件让循环停止。考试题会根据题干设计问法：有时问“最后位置”，有时问“第一次出现的位置”。

关键：如果数据里目标出现多次，程序是否停止会影响位置变量。
